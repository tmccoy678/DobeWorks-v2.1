# Security policy

Security fixes target the latest commit on `main`. This development snapshot has no versioned support line or security certification.

Do not put credentials, personal records, exploit details, or other sensitive material in a public issue. Contact [Taylor (@tmccoy678)](https://github.com/tmccoy678) through an established private channel. If none exists, open an issue that asks only for a private contact method.

Include the affected commit, expected and observed behavior, a small sanitized reproduction, impact, environment, and any known mitigation. Synthetic fixtures are preferred.

The demonstrations do not install background services, grant task authority, or authorize device or credential access. Their structured results describe the supplied synthetic inputs; a passing result does not establish that evidence is true or that later work is approved.
