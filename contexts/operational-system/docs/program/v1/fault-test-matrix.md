# Applicable Fault-Test Matrix

Every row is applicable to v1 unless a later architecture removes the affected role and records traceable non-applicability. These are planned tests, not passing evidence. Hardware faults must use safe simulation or a separately authorized controlled procedure; Phase 1 authorizes neither device operation nor fault injection.

| `FLT-ST-002` | Seagate or role becomes read-only | Write preflight or operation returns read-only status | Stop writes; preserve source and error evidence; reads only if role contract permits | Diagnose non-destructively, prove no partial authoritative change, revalidate role | `EV-P6-STORAGE-FAULT` / 6 | Taylor for any repair/write-risk decision |

## Pass rule

A fault row passes only when the exact applicable architecture has objective evidence for detection, containment, degraded behavior, recovery, and resume authority; the evidence is tied to the tested generation and any discrepancy is closed. A simulated test must state what the simulation does and does not establish. No row passes from prose alone.
