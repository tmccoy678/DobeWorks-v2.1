# Publish the source snapshot without expanding the identity boundary

The repository owner authorized the existing public DobeWorks source snapshot to be made usable by ordinary downloaders. Current instructions, examples, links, and ordinary tests may therefore assume public read access and must not depend on Taylor's computer.

This decision publishes the repository's code and documentation under their stated licenses. It does not publish private source photographs, create a hosted service or organization, qualify the synthetic demonstrations for production, or approve unrelated DobeWorks identity assets. Historical evidence may retain the environment it originally recorded when changing it would falsify provenance; current executable paths must be portable.
